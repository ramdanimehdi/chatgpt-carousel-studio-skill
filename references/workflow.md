# Content and visuals
Choose the template according to the teaching purpose:
- Comic/meme: one relatable situation, restrained humor, actionable conclusion.
- Cinematic: coherent visual story, large short headlines, strong contrast.
- Clean authority: white background, navy text, one accent, one point per slide.
- Diagram/system: RTL flow, accurate labels, enough space to follow dependencies.
- Handwritten notes: paper texture, readable Arabic, teal/gold accents, sparse notes.

Avoid combining every style in a single carousel. Use the user's approved references.
Supply captions, accessible alt text, CTA and any promised resource before publication.
For a comment keyword, prepare the actual resource and variants; distinguish a prepared reply from a configured automation. Do not send private editor URLs to followers.
Generate only the artwork needed for the request; do not promise save/share performance.
