# ChatGPT Carousel Studio Skill

أنشأ هذا المشروع مهدي رمضاني، ونعمل على تحسينه وتطويره باستمرار.

سكيل مستقل لإنشاء الكاروسيل باستخدام ChatGPT، مع محرر عربي قابل للتخصيص وتشغيل على Windows وmacOS والسحابة. لا يحتوي معلومات حسابات المؤسس.

## التثبيت
ضع رابط المستودع داخل ChatGPT Work واطلب فحص السكيل وتثبيته وتخصيصه لمجالك وجمهورك وهويتك. يتطلب بيئة تدعم المهارات وتنفيذ الملفات.

## تشغيل المحرر
يتطلب Node.js 22.13+ وPython 3. انسخ قالب المحرر بأمر `py scripts/copy_editor.py --output C:/carousel-studio` على Windows أو `python3 scripts/copy_editor.py --output ~/carousel-studio` على Mac، ثم داخل المجلد الناتج شغّل `npm install` ثم `npm run dev`. افتح http://localhost:3000.

للسحابة: انشر assets/editor على استضافة Node.js أو استخدم Dockerfile المرفق. أضف HTTPS وحماية دخول. GitHub Pages لا يشغّل واجهة GHL الخلفية. الخطوط تُحمّل من Google Fonts وتحتاج اتصالًا بالإنترنت.

## GoHighLevel
التكامل اختياري، ويشترط إضافة حسابات التواصل الاجتماعي مسبقًا إلى Marketing → Social Planner داخل GHL الخاص بالمستخدم. أدخل Location ID وUser ID والتوكن الخاص بك في إعدادات الاتصال؛ لا تضع المفاتيح في المستودع أو الشات.

## الوظائف
تصدير PNG وZIP، نسخ احتياطي، شريحة خدمات المستخدم، تسجيل وقت النشر، استبعاد المنشور والمجدول من التكرار، ونشر دفعة بفاصل 3 ساعات. الصور تُنتج بأداة GPT المتاحة ثم تُستورد؛ النص المطبوع داخل الصورة يحتاج إعادة توليد لتغييره. سكريبتات الريلز لا تُنشر كفيديو.

## التحقق
اجتازت نسخة الكود اختبارات 15 وTypeScript وبناء الإنتاج على Linux. أوامر التشغيل مشتركة بين الأنظمة؛ لم تُنفذ اختبارات أصلية على Windows أوMac أو نشر فعلي بحسابات اجتماعية. البيانات محلية لكل متصفح؛ الاستضافة السحابية لا تضيف مزامنة بين الأجهزة. منع التكرار محلي وليس ضمانًا بين أجهزة مستقلة.
